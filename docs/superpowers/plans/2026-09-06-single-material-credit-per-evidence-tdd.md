# Single Material Credit Per Evidence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent one official RFC erratum from creating more than one 1 GEN material credit in the same reserve, even when the evidence is resubmitted under a new review ID after settlement.

**Architecture:** Append permanent per-reserve indexes for credited errata IDs and canonical RFC Editor URLs. Reject already-credited evidence in `open_review` before any review state changes, and mark both indexes atomically on the first funded `MATERIAL_IMPACT` settlement. Preserve retries after `NO_MATERIAL_IMPACT` and `UNVERIFIABLE`, and preserve one independent credit per reserve.

**Tech Stack:** Python 3.12, GenLayer Python SDK/GenVM runner `py-genlayer:1jb45aa8ynh2a9c9xn3b7qqh8sm5q93hwfp7jqmwsfhh8jpz09h6`, `genvm-lint`, `genlayer-test` direct mode, Node.js 24, React/Vite/Vitest, Playwright, `genlayer-js` 1.1.8, GenLayer Studionet, Vercel CLI.

- [ ] **Step 6: Add deterministic evidence-key helpers**

Add after `_official_url`:

```python
    def _credited_errata_id_key(self, reserve_id: str, errata_id: str) -> str:
        return reserve_id + "|id|" + errata_id

    def _credited_errata_url_key(self, reserve_id: str, errata_id: str) -> str:
        canonical_url = "https://www.rfc-editor.org/errata/eid" + errata_id
        return reserve_id + "|url|" + canonical_url

    def _has_material_credit_for_evidence(
        self,
        reserve_id: str,
        errata_id: str,
    ) -> bool:
        id_key = self._credited_errata_id_key(reserve_id, errata_id)
        url_key = self._credited_errata_url_key(reserve_id, errata_id)
        id_credited = id_key in self.credited_errata_ids and self.credited_errata_ids[id_key]
        url_credited = url_key in self.credited_errata_urls and self.credited_errata_urls[url_key]
        return id_credited or url_credited

    def _mark_material_credit_for_evidence(
        self,
        reserve_id: str,
        errata_id: str,
    ) -> None:
        id_key = self._credited_errata_id_key(reserve_id, errata_id)
        url_key = self._credited_errata_url_key(reserve_id, errata_id)
        self.credited_errata_ids[id_key] = True
        self.credited_errata_urls[url_key] = True
```

Do not add a public test-only view for these indexes. Canonical business outcomes already prove the invariant.
